गांव के किनारे एक छोटा सा तालाब था। हर सुबह मीरा वहां बैठकर सपने बुनती। एक दिन उसने घायल पक्षी देखा, उसे घर ले आई। दवा और प्यार से पक्षी ठीक हुआ। उड़ते समय उसने मीरा की हथेली छुई। तब मीरा समझ गई, सच्ची दया लौटकर खुशियां बन जाती है। उस दिन से गांव में उसकी मुस्कान कहानी बनकर फैल गई। और सबने मदद सीख ली। हमेशा के लिए। साथ।
